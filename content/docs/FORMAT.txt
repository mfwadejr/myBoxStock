Documentation pages (Markdown subset). One file per page in content/docs/reseller/ or content/docs/host/, named NN-slug.md.

Header (required, first lines):
---
title: Inventory
summary: One or two plain sentences saying what this page helps you do.
keywords: comma, separated, words people might type when they look for this
order: 3
covers: nav:inventory, Add item, Date received, Tested on   (every menu key as nav:<key>, plus every button, field, tab and setting the page explains)
---

Body: ## and ### headings, paragraphs, "- " bullets, "1. " numbered steps, "> " tip/note box, **bold**, `code`, and links [text](#/docs/slug).
Screenshots: one line on its own, ![Alt text](shot:NAME "Caption text"). NAME is lowercase letters, digits and hyphens (for example reseller-home).
Both files must exist: public/assets/docs/NAME-laptop.png and NAME-phone.png (each under 250 KB). Alt text and caption are required. The phone picture shows on narrow screens.
Make them with tools/docs-shots/run.mjs (see tools/docs-shots/README.md). The caption is searchable; the steps must still read fine without the picture. Made-up demo data only.
No HTML, no other images, no other Markdown. Links only to #/docs/<slug> (screenshot lines use shot:NAME).
